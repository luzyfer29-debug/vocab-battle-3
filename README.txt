Kinder-Auswertung · Antworten und Wiederholfehler live sichtbar

Dateien im ZIP im Repository-Hauptordner ersetzen:
- app.js
- kinder-app.js
- index.html
- kinder.html

Die Schiedsrichter-Liveübersicht zeigt Antworten und Wiederholfehler direkt an der Übung. Vokabelarbeits- und Grammatikentwürfe werden parallel in der Aktivitätsübersicht gespeichert. Offene Fehler bleiben bis zur richtigen Wiederholung sichtbar; Aktivitäten und Fehler aus mehreren Geräten werden zusammengeführt. Bereits vorhandene Aktivitäten werden angezeigt. Ältere Antworten lassen sich nur übernehmen, wenn sie noch auf dem Kindergerät gespeichert sind.
